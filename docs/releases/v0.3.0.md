## Re:Novel AI v0.3.0

以 v0.2 为基础的整体重构：界面不变，内部按「业务层 + 界面组件」重新组织，并新增记忆一致性、文风、续写，
提供 Windows 绿色版。

### 下载与使用

- **Windows 绿色版**：下载下方的 `ReNovel-v0.3.0-windows.zip`，完整解压后双击 `ReNovel.exe`，浏览器会自动打开。
  首次启动会引导你选择模型服务（OpenAI、DeepSeek、硅基流动、Gemini、Ollama 本地或自定义）并填写 API Key。
  所有数据保存在 `ReNovel.exe` 旁边的 `data` 文件夹，详见压缩包里的 `使用说明.txt`。
- **源码运行**：需要 Python 3.11 或更高版本，见 README。

### 新功能

- **记忆一致性**
  - 向量记忆改为 SQLite + numpy；向量可由本地中文模型 bge-small-zh 生成（首次使用自动下载，可换镜像），
    也可用 OpenAI 兼容的 `/embeddings` 接口
  - 章节记忆：每章的摘要、出场角色、关键事件、伏笔，只在正文变化时重新整理
  - 角色档案：别名合并、性格、状态变化、人物关系，可手动修订
  - 改写时只参考当前章节之前的内容（不剧透）；审校按全书检查人设（OOC）、时间线和伏笔，并指出冲突出处
- **文风**：从原文提炼文风档案，或套用预设（白描 / 古风 / 轻小说），也可手动编辑；改写按档案执行，审校给出文风贴合度
- **续写**：在全书末尾续写新章节，或在某段之后续写；可填大纲和篇幅，审校后作为草稿，采纳后才保存并更新记忆
- **段落版本与历史**：AI 结果作为候选，可撤销、重新采纳；每次保存保留旧版本（每章最近 20 个），可以恢复
- **设置界面**：服务预设、测试连接、审校策略（手动 / 自动、及格分、重试次数）、各功能分别指定模型
- **首次启动引导** 与 **Windows 绿色版**（打包后自动做启动自检）

### 改进与修复

- 每个浏览器标签页独立会话；多个标签页同时编辑同一章时，保存前会询问是否覆盖
- 批量精修：可写入副本、随时停止、断点续跑；改写期间被手动保存的章节不会被覆盖
- 导入：自动识别 GBK、Big5 等编码；分章更准确
- 模型调用改用 openai SDK，移除 LangChain；代理只作用于本程序
- 审校弹窗的「重试」、全局指令、人物关系上下文等原有问题已修复

### 从 v0.2 升级

- 把旧版本的 `data` 文件夹复制到新版本旁边即可（源码运行时就是项目里的 `data` 目录）。
- 旧版本的向量记忆（ChromaDB）会在第一次启动时自动从已保存的章节重建，期间检索会稍等片刻。
- 旧项目在设置里点「整理记忆」即可生成章节记忆和角色档案。

### 已知事项

- 本地向量模型的下载在开发环境里无法实测；如果下载失败，请在「设置 → 记忆 (向量)」里更换镜像，或改用 API。
- 部分杀毒软件可能误报 PyInstaller 打包的程序，可加入信任列表。
