Re:Novel AI —— Windows 绿色版使用说明
==================================

一、启动
  1. 把压缩包完整解压到任意文件夹（路径里最好不要有特殊字符）。
  2. 双击 ReNovel.exe。会出现一个黑色窗口（程序日志，使用期间不要关闭），
     稍后浏览器自动打开 http://127.0.0.1:8080 。
  3. 关闭黑色窗口即退出程序。

二、第一次使用
  1. 首次打开会弹出「欢迎使用」：选择模型服务（OpenAI、DeepSeek、硅基流动、Gemini、Ollama 本地或自定义），
     填入 API Key，点「测试连接」，成功后点「保存并开始」。
  2. 点右上角「+」导入 TXT 小说（自动识别 UTF-8 / GBK / Big5 编码并分章）。
     导入时可以选择「整理章节记忆并建立人物图谱」，会调用模型逐章分析。
  3. 之后可在右上角齿轮「设置」里分别设置各功能使用的模型、审校策略和向量记忆。

三、数据保存在哪里
  所有数据都在 ReNovel.exe 旁边的 data 文件夹里：
    data\config.json      设置（含明文 API Key，请勿分享给他人）
    data\projects\        小说、章节、章节记忆、文风档案、人物图谱
    data\memory.db        向量记忆
    data\models\          首次使用本地向量模型时自动下载的模型
  备份或换电脑时，复制整个文件夹即可；升级新版本时，把旧版本的 data 文件夹复制到新版本旁边。

四、常见问题
  · 浏览器没有自动打开：手动访问 http://127.0.0.1:8080 。
  · 端口被占用：在黑色窗口所在目录用命令行设置环境变量后启动，例如
      set RENOVEL_PORT=8090 && ReNovel.exe
  · 本地向量模型下载失败：在「设置 → 记忆 (向量)」里更换下载镜像，或改用 API 生成向量。
  · 杀毒软件误报：本程序由 PyInstaller 打包，部分杀毒软件可能误报，可加入信任列表。
